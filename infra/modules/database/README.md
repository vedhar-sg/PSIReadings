# Database module

Amazon RDS for the OutSystems platform database. SQL Server is the default; Oracle is supported.

- **Master password:** generated and rotated by RDS in Secrets Manager (`manage_master_user_password`). It never appears in code, variables or state.
- **Encryption and isolation:**
  - storage, the master secret and Performance Insights use the environment KMS key;
  - not publicly accessible;
  - ingress on the database port only from the given security groups.
- **Resilience:** gp3 storage with autoscaling, automated backups (point-in-time recovery), optional Multi-AZ, deletion protection and a final snapshot.
- **Monitoring:** enhanced monitoring, and engine logs exported to CloudWatch.

Part of the [OutSystems 11 on AWS](../../README.md) stack. Tests live in `tests/` and run with `terraform test` (mocked AWS provider, no credentials needed).

## Usage

```hcl
module "database" {
  source = "../modules/database"

  name           = "os11-dev"
  vpc_id         = module.network.vpc_id
  subnet_ids     = module.network.database_subnet_ids
  instance_class = "db.m6i.large"
  kms_key_arn    = module.security.kms_key_arn

  allowed_security_group_ids = {
    controller = module.platform.security_group_ids.controller
    frontend   = module.platform.security_group_ids.frontend
  }
}
```

## Inputs

| Name | Description | Type | Default | Required |
|------|-------------|------|---------|:--------:|
| allowed\_security\_group\_ids | Security groups allowed to reach the database port, keyed by a label. | `map(string)` | n/a | yes |
| instance\_class | RDS instance class. | `string` | n/a | yes |
| kms\_key\_arn | KMS key for storage, the master secret and Performance Insights. | `string` | n/a | yes |
| name | DB identifier / name prefix (e.g. os11-prod). | `string` | n/a | yes |
| subnet\_ids | Isolated database subnet IDs (at least two AZs). | `list(string)` | n/a | yes |
| vpc\_id | VPC ID. | `string` | n/a | yes |
| allocated\_storage\_gb | Initial storage in GiB. | `number` | `100` | no |
| apply\_immediately | Apply modifications immediately instead of in the maintenance window. | `bool` | `false` | no |
| backup\_retention\_days | Automated backup retention (point-in-time recovery window). | `number` | `7` | no |
| backup\_window | Daily backup window (UTC). | `string` | `"17:00-18:00"` | no |
| character\_set\_name | SQL Server collation or Oracle character set. Null keeps the RDS default (SQL\_Latin1\_General\_CP1\_CI\_AS / AL32UTF8). | `string` | `null` | no |
| deletion\_protection | Block deletion of the instance. | `bool` | `true` | no |
| engine | RDS engine. SQL Server: sqlserver-se \| sqlserver-ee \| sqlserver-web \| sqlserver-ex. Oracle: oracle-se2 \| oracle-ee. | `string` | `"sqlserver-se"` | no |
| engine\_version | Engine version or major-version prefix (e.g. 16.00 for SQL Server 2022). Check the OutSystems 11 system requirements. | `string` | `"16.00"` | no |
| license\_model | license-included or bring-your-own-license. | `string` | `"license-included"` | no |
| maintenance\_window | Weekly maintenance window (UTC). | `string` | `"sun:18:30-sun:19:30"` | no |
| master\_username | Master user name. The password is generated by RDS in Secrets Manager. | `string` | `"osmaster"` | no |
| max\_allocated\_storage\_gb | Storage autoscaling ceiling in GiB. | `number` | `500` | no |
| monitoring\_interval | Enhanced monitoring interval in seconds (0 disables). | `number` | `60` | no |
| multi\_az | Deploy a synchronous standby in a second AZ. | `bool` | `false` | no |
| performance\_insights\_enabled | Enable Performance Insights (not available on every instance class / edition). | `bool` | `false` | no |
| skip\_final\_snapshot | Skip the final snapshot on destroy. | `bool` | `false` | no |
| tags | Extra tags (e.g. the AWS Backup selection tag). | `map(string)` | `{}` | no |
